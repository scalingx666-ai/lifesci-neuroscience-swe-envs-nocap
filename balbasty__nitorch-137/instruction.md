## Summary
- **uniseg forces TkAgg** (#114): `nitorch/cli/segmentation/uniseg/cli.py` no longer calls `matplotlib.use('TkAgg')`. It uses the default backend selection (Agg when headless), as #133 did for register. If matplotlib is missing, it warns and turns plotting off.
- **`@loss mi -p` silently dropped** (#114): the register parser no longer offers `-p/--patch` for `mi`/`nmi`, so `@loss mi -p 5` is now a parse error. `ent` never had it, and the help text did not list it. `lcc`/`lgmm` `-p` are unchanged.
- **`_push_grad_fixed` Hessian docstring** (#114): replaced "approximates it as before" with a precise note. The pushed blocks are the block row-sums of Pᵀ diag(H) P. This majorises the full GN Hessian (inter-node cross terms dropped) and inflates its diagonal (about 3-4x for a 2x coarser field), so steps are conservative but the fixed point is unchanged. `ShootModel.propagate_grad` now notes that it does not use this path.
- **Rotate after `jg`** (#114): the gradient path computes `jg` with the unrotated image gradients and rotates the (*fixed, D) result by Leftᵀ. The Hessian path still rotates `mugrad`, but only when a Hessian is requested; rotating the packed symmetric block was not simpler.
- **Exact GN Hessian test** (#114): two new tests build JᵀJ from an autograd Jacobian (12³ fixed image). On the integer-shift lattice, the pushed blocks equal the exact diagonal blocks (1e-10). On the 2x coarser 7³ field, blockdiag(pushed) − JᵀJ ⪰ 0 (min eigenvalue ≥ −1e-12·λmax). They take about 4 s each, so they are marked `slow`. Also added a test comparing the new left-affine path with the old formula (≤1e-12, float64, on the coarse/rotated/subvoxel lattices).
