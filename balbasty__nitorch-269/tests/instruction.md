## `docs/cli/reference/images/metrics.md`
- **Label metrics:** labels found only in the prediction are never scored, so they don't lower the `macro` average. `hausdorff` is the exception (see below).
- **New warning box:** if `-x` removes every reference label, label metrics are written as empty objects without `-s`. With `-s macro`/`micro`/`weighted`, `metrics` stops with `[ERROR] division by zero`, exits with status 1 and writes no file. `macro` and `micro` were run; `weighted` goes through the same empty sums.
- **Hausdorff:**
  - It is a *directed* distance, from prediction to reference, not the symmetric max(d(P,R), d(R,P)).
  - For the symmetric distance, run `metrics` again with `-p`/`-r` swapped and a different `-o`, and keep the larger value for each label.
  - A label that is missing from either image is `inf`. It is excluded from the averages, with a warning that is printed only when `-s` is given.

## `nitorch/cli/misc/metrics/parser.py` (help text only)
- `hausdorff   Hausdorff distance (directed: prediction -> reference)`
- Under `-m`: "Label metrics other than hausdorff only score labels present in the reference."
