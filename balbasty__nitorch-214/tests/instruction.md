# Issue

**Title:** FIX(register): @@optim -o true/false; save shooting steps for reslice

## Description

Part of #171. This is a  and #200, for issues found while working on them.

1. **`@@optim nes|ogm -o`** had no boolean conversion, so `-o true` wrote a file literally named `true`. It now behaves like `@@fix`/`@@mov -o` after #201:
   - a bare `-o`, `true` or `yes` gives the default path, `{dir}{sep}momentum.nii.gz` (`affine_momentum.json` for `@affine`);
   - `false` or `no` writes nothing;
   - any other value is used as a path.

   The default is now `False` (it was `''`), and `check_options` validates these templates before the fit.
2. **Shooting `steps`.** The JSON written next to a `shoot` velocity field stored the penalty and the factor, but not the number of integration steps. Since #200, `reslice` reads `steps` and `fast` from that JSON, but it fell back to `shoot`'s default of 8.
   - The JSON now also stores `steps`, the value actually used during registration.
   - It also stores `fast`, which is always `True` because `ShootModel` uses `shoot`'s default.
   - `reslice` needed no change.

**Docs:** a separate writer subagent updated `register.md`:
- the `@@optim -o` row now reads `[PATH | true | false]`, with the default paths;
- the shoot JSON row lists `steps` and `fast` and links to `reslice`.

**Tests:** in `nitorch/tests/test_cli_register_options.py`:
- a parser test over affine/nonlin × nes/ogm × {none, `-o`, `true`, `yes`, `false`, path};
- a test that a bad template is rejected;
- a tiny shoot registration (12³, 1 iteration, `-s 3`). It checks that the JSON has `steps == 3` and `fast`, and that `reslice`'s `exponentiate_transforms` passes `steps=3, fast=True` to `spatial.shoot`, which is monkeypatched.

Before the fix, 18 fail and 8 pass; after it, all 26 pass. `pytest -k "register or reslice"` gives 1113 passed and 39 skipped.

**Behaviour changes**
- `@@optim -o true`/`false` now means the default path or no output.

- Shoot JSON files written before this change still lack `steps`, so `reslice` keeps using 8 steps for them.
