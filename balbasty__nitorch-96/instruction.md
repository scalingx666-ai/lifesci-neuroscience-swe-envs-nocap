## Summary

- **`mind` / `rmind` in 2D (silent)**: the variance was normalized by its mean over the last **three** dimensions, whatever `dim` was. In 2D with a channel dimension, this averaged across channels, so each channel's descriptor depended on the other channels. Without a channel dimension, it failed. It now averages over spatial dimensions only. Results are unchanged in 3D (`range(-3, 0) == range(-dim, 0)`).
- **`rmind` with radius < √2**: the first ring is only used to normalize the other rings. With a single ring, no feature was left, which failed with an obscure `max(): Expected reduction dim 0 to have non-zero size`. It now raises an explicit `ValueError`. `register --mind FWHM 1` reaches this, and so does `--mind FWHM 1.5`, since `make_image` casts the radius to `int`.
- **`register --mind` help**: it stated a default radius of 0, while the actual default is 2.

This touches `rmind` near the change in #93 (sorting `sqdist`), but I checked that the two branches merge cleanly in either order.
