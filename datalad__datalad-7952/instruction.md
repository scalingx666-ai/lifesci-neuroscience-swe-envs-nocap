# Issue

**Title:** RF(CI): measure subprocess coverage via coverage's `patch = subprocess`, drop tools/coverage-bin

## Description

Replaces the `tools/coverage-bin` wrappers with coverage's own `[run] patch = subprocess` (as in con/duct#452), so the coverage of the `datalad` CLI, the special remotes and `git-credential-datalad` run by tests is measured. The wrappers' data was never combined: on master `customremotes/datalad.py` and `gitcredential_datalad.py` are at 0%.

To keep it cheap, CI now runs the PyPI git-annex binary directly instead of its Python console script, which coverage would otherwise start in on every git-annex call. That alone also speeds up test runs.

Changelog snippet included (`semver-tests`).
