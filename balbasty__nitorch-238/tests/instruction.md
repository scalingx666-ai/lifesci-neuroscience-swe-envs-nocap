# Issue

**Title:** DOC(register): affine position is about model composition, not loss space

## Description

## Summary

The "Position of the affine" section of the `register` reference claimed that `-p/--position` decides which space images are resampled into (and hence where the loss is evaluated). That is incorrect: the position decides where the affine sits in the forward (fixed-to-moving) model:

| Position | Forward model |
| --- | --- |
| `mov` | $A(\varphi(x))$ |
| `fix` | $\varphi(A(x))$ |
| `sym` | $A^{1/2}(\varphi(A^{1/2}(x)))$ |

The loss is always computed on the fixed grid. It is also computed in moving space (through the inverted forward model) only when the loss is symmetric (`-s`), whatever the position.
