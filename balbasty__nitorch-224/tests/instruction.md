## Description

Part of #171. This is a , for two items found while working on it.

1. **`vopt <file>` without `-i`** printed the unclear `[ERROR] Unknown tag <file>`, because every argument the parser did not recognise went to the same `else` branch.

**Registration scan:** every `commands['...']` entry under `nitorch/cli` already has a `try/except ParseError`. The only commands that did not return 1 are `resize` and `autoreg`, which #221 and #220 already fix, so they are left out of this PR.
