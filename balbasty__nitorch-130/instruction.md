# Issue

**Title:** Regularise MSE precision with a Gamma prior; reject non-finite optimiser steps

## Description

Part of #114

## Summary
- **MSE precision prior** (`losses/mse.py::weighted_precision`, used by `MSE` and by the robust losses in `robust.py`). The estimated precision was `N/S`, which goes to infinity as the residual goes to zero. This is the cause of the NaN affine parameters diagnosed in #105. It is now the posterior mean under a conjugate Gamma prior on λ:
  - λ ~ Gamma(ν0/2, ν0·s0²/2); posterior Gamma(ν0/2 + N/2, ν0·s0²/2 + S/2), with S = Σ w r² and N = Σ w
  - λ̂ = (ν0 + N) / (ν0·s0² + S), i.e. 1/λ̂ = (ν0·s0² + N·σ̂²)/(ν0 + N), a weighted average of the prior variance and the sample variance σ̂² = S/N
  - It is computed per channel and uses the same mask and IRLS weights as before.
  - Defaults:
    - `prior_fraction=1e-3`: s0² = 1e-3 × the weighted intensity variance of the fixed image within the mask, i.e. a residual SD of about 3% of the image SD. If the image is constant inside the mask, its second moment is used instead, and machine epsilon if it is all zeros.
    - `prior_dof=4` pseudo-voxels: enough to cap λ on tiny masks, with relative weight ν0/(ν0+N) otherwise.
    - `prior_variance` sets s0² directly.
  - These are options of `MSE`. They are not wired into the CLI.
  - Effect on a typical case (64³ volume, noise SD 0.1): λ changes by 1.5e-5 relative. ν0 = 0 gives the old ML estimate.
  - Identical images give λ̂ = (ν0+N)/(ν0·s0²). This equals 1/s0² only when N ≪ ν0 (tested). Otherwise it is finite but grows like N/ν0 · 1/s0², which is inherent to the requested posterior-mean form.
- **Non-finite steps** (`optim/base.py`, `optim/wolfe.py`):
  - `Optim.step` without a line search: a non-finite search direction, or a non-finite new loss (when the old one was finite), keeps or restores the previous parameters.
  - `StrongWolfe`:
    - A non-finite start returns step 0.
    - A non-finite loss or directional derivative at a trial step bisects back towards the last finite point, within `max_iter`. This replaces an unbounded halving loop that ignored the gradient.
    - In the zoom phase, a non-finite value stops the search with the best finite point.
    - A non-finite final value returns step 0.
  - The backtracking and step-size searches already reject NaN, because `NaN < loss0` is False. They are unchanged.
  - Behaviour is unchanged when everything is finite.

Overlap: #120 changes `robust.py` but not `weighted_precision`. Robust losses pick up the prior through the default arguments, and nothing here conflicts with #120.
