# Issue

**Title:** FIX(losses): weight linear-elastic penalties by their own factors

## Description

## Summary

`nn.GridLoss` multiplied the divergence and shear (linear-elastic) energies by the **membrane** factor instead of `lame[0]` / `lame[1]`:

```python
if lame1:
    loss += membrane * spatial.lame_div(x, **prm).mul(x).sum(-1)
if lame2:
    loss += membrane * spatial.lame_shear(x, **prm).mul(x).sum(-1)
```

**Impact on autoreg (silent).** autoreg collapses all its regularizers into a `GridLoss`. Its default regularization of FFD/diffeomorphic transforms includes `LinearElasticLoss(factor=(0.05, 0.2))`, so with the default membrane factor (0.001) these penalties were 50× and 200× weaker than intended. They were also inconsistent with the Greens kernel used to precondition diffeomorphic updates, which uses the correct factors.

⚠️ This changes autoreg's default results for non-linear transforms: they are now more regularized, as originally intended.

Also fixes `autoreg.struct.LinearElasticLoss.call`, where the shear factor multiplied the divergence term too. That class is currently always collapsed into a `GridLoss` before use, so it had no effect.

## Tests
- New `nitorch/tests/test_grid_loss.py` checks both losses against explicitly weighted energies. It fails on master and passes here.
- An end-to-end autoreg FFD run on a synthetic pair still converges.
