# Issue

**Title:** DOC(spatial): numerical inversion is not differentiable

## Description

Part of #171. Owner decision: it is expected that the numerical inversion can't be backpropagated through. This PR documents that.

Docstrings only, no behaviour change:
- **`grid_inv`** (`nitorch/spatial/_grid_inv.py`), new paragraph in Notes: the inversion is not differentiable, because backpropagating fails inside the multigrid solver. Call it on tensors that don't require grad, or under `torch.no_grad()`.
- **`shoot`** (`nitorch/spatial/_shoot.py`), at the end of the `inversion` description: `'push'` and `'newton'` can't be backpropagated through, while `'default'` is differentiable (since #265).

The CLI reference pages are left unchanged, because the CLI is unaffected: registration computes its own gradients. `docs/python/index.md` has no section on `grid_inv` or `shoot` that could hold the note.
