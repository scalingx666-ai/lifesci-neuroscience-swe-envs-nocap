<ul>
<li>Contended <code>FileLock</code> and <code>SoftFileLock</code> acquisitions now raise <code>Timeout</code> when elapsed time reaches the requested timeout. <p>New feature release in the 5.5.x series.</p>

Note that passing <a href="https://numpy.org/doc/stable/reference/arrays.scalars.html#numpy.float64">float64</a> explicitly still results in <code>float64</code> arrays. (<a href="">#1592</a>) (Bhaskar Gurram, reviewed by CM)</li>
<li>Cifti2 <code>*Axis</code> classes now accept any <a href="https://docs.python.org/3/library/numbers.html#numbers.Integral">Integral</a> indices, allowing them to be indexed by NumPy integers (<a href="">#1581</a>) (Don Yin, reviewed by CM)</li>
<li>Update <a href="https://nipy.org/nibabel/reference/nibabel.nifti1.html#nibabel.nifti1.Nifti1Image.as_reoriented">Nifti1Image.as_reoriented</a> to reorient sform and qform independently and preserve (q/s)form codes (<a href="">#1546</a>) (Cedric Conday, reviewed by CM)</li>
<li>Validate SpatialHeader zooms are positive in spatial dimensions, non-negative in other dimensions (Siddhardha Nanda, reviewed by CM) (<a href="">#1596</a>)</li>
