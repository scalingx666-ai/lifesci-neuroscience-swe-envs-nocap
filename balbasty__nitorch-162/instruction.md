## Description

## Summary

Part of #114 (item: "`nes`/`ogm -o/--output` momentum maps are parsed but not implemented").

**Wiring check.** The option was wired in the CLI but ignored by the optimizer. `@@optim nes|ogm -o [PATH]` is parsed (default `''`; a bare `-o` gives `{dir}{sep}momentum.{iter}.nii.gz`). `cli._main` then passes every `@@optim` option to `make_{affine,nonlin}_optim(**options.*.optim)`, and those pass it on to `Nesterov(...)` / `OGM(...)`. There, `Optim.__init__(**opt)` swallowed it without a word, the same way it swallows `name` and `fmg`. No code formatted the `{dir}`/`{iter}` template or wrote a file. Since the option is wired, this PR implements it.

### What is written

`Nesterov`, `OGM` (and `Momentum`) keep `delta` as their state: the last step of the auxiliary sequence, `y{k+1} - y{k}`, which includes the learning rate. It has the same shape as the optimised velocity. That state is the "momentum map". It is written after each **completed** step, so after the line search, in the same format as the velocity output: `io.savef(delta, fname, affine=nonlin.affine)`.

- Template fields: `{dir}` (`-o/--output-dir`, or the folder of the first fixed image, as for the other outputs), `{sep}`, `{name}` (nonlinear model name, e.g. `svf`) and `{iter}` (Python format specs work, e.g. `{iter:03d}`).
- `{iter}` counts this optimizer's steps over the **whole run** (all pyramid levels and interleaved passes), starting at 1, so files never overwrite each other. Each file is written on the lattice of its own pyramid level, with that level's affine. The last file has the shape and affine of the written velocity.
- **`@affine @@optim nes|ogm -o`:** for an affine model the momentum is a vector of 6–12 Lie-algebra coefficients, not a map. The option is ignored with a `UserWarning` and nothing is written. The help now says `(@nonlin only)`.
- Without `-o`, nothing changes. The default is `''`, which is treated as no output.

### Changes
- `optim/base.py`: new no-op hook `Optim.after_step()`. `OptimIterator.step` and `InterleavedOptimIterator.step` call it after each step they run themselves. When a sub-optimizer has its own iterator, that iterator calls it, so each step is written once.
- `optim/accelerated.py`: `AcceleratedFirstOrder(..., output=None)`. `output` is a callable that receives `delta`. `''`/`None` means no output; any other non-callable raises `TypeError`, so a template string can no longer be dropped silently.
- `pairwise_postproc.py`: `MomentumWriter(fname, nonlin, odir, name, verbose)`. It reads `nonlin.affine` when it writes, so it follows pyramid up/downsampling, which happens in place. File names are printed at `-v 2`.
- `register/cli.py`: builds the writer for the nonlinear optimizer and warns for the affine one. `odir` is now computed before the optimizers are built (same expression). I also removed a local `import warnings` inside `_main`: it made `warnings` a local name for the whole function, so the new warning raised `UnboundLocalError`.
- `register/parser.py`: help text `-o, --output [PATH] Write the momentum map after each step (@nonlin only): [False], True={dir}/momentum.{iter}.nii.gz`.

## Tests

New `nitorch/tests/test_register_momentum.py`, 13 tests, about 35 s on CPU (TorchScript backend):
- Hook: `Nesterov`/`OGM`/`Momentum` under `OptimIterator(max_iter=4)` call `output` 4 times. The last state equals `optim.delta`; the first equals `-lr·∇f(x0)`. In an `InterleavedOptimIterator`, the nonlinear sub-optimizer writes once per own step (2 passes × 3 steps = 6).
- `output` must be callable (a template string raises), `''` is none, the parser defaults are as above, and `make_nonlin_optim` forwards `output`.
- `MomentumWriter`: file names with `{name}`/`{iter:02d}`, data and affine round-trip.
- End-to-end `_cli` on 10³ images:
  - `@nonlin svf @@optim nes|ogm -n 3 -o` writes `momentum.{1,2,3}.nii.gz`, each finite and non-zero, with the shape and affine of `svf.nii.gz`.
  - A custom path over 2 pyramid levels writes `svf_001…004`; the coarse level is on its smaller lattice.
  - Without `-o`, nothing is written.
  - `@affine translation @@optim nes -o` warns, writes no momentum files, and still writes the `.lta`.
