# Issue

**Title:** FIX(cli): Conversions.bool reads 'f' as false

## Description

Part of balbasty/nitorch#171.

## Summary
`nitorch.core.cli.Conversions.bool` listed `'t'` among the "false" spellings instead of `'f'`. So `f` was not recognised and came back unchanged as the string `'f'`, which is truthy. Every command that uses this converter for a yes/no option was affected.

## Changes
- Fix the tuple: `('f', 'false', 'n', 'no')`.
- Add `nitorch/tests/test_cli_conversions.py`, which tests the true and false spellings and the pass-through of other words. The `f`/`F` cases fail before this fix.
