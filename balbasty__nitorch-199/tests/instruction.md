# Issue

**Title:** FIX(meanspace): honour -l and device, convert pad unit, no temp file with -o no

## Description

Part of #171. I reproduced all three bugs before fixing them.

1. **`-l` and `--cpu`/`--gpu`** were parsed and then ignored.
   - `-l LAYOUT` is now passed to `mean_space`, so the output affine uses the requested layout.
   - A new `setup_device()` handles the device options:
     - `--gpu [N]` selects `cuda`/`cuda:N`, and falls back to the CPU with a warning if CUDA is unavailable;
     - `--cpu N` sets the number of threads.
   - The device is also passed to `reslice` with `-r`. The affine is moved back to the CPU before it is printed or saved.
2. **The pad unit was never converted.** Any unit other than `%` was used as voxels of the mean space. The fix is in `spatial._affine.compute_fov`:
   - `%`/`pct` keep the percentage behaviour;
   - `vox`/`voxel(s)` mean voxels;
   - anything else means mm, converted with the output voxel size, as `-v` already does.
3. **`-o no`** always left a `NamedTemporaryFile(delete=False)` behind.
   - Without `-r`, nothing is written now.
   - With `-r`, the mock image goes into a temporary directory, which is removed in a `finally` block.

**Docs:** a separate writer subagent updated `meanspace.md`:
- `-l`;
- the device options;
- the pad units;
- the `-o no` behaviour.

**Tests**
- The new `nitorch/tests/test_cli_meanspace.py` has 12 tests. On `master`, 10 fail and 2 pass; the two that pass check behaviour this PR doesn't change. With the fix, all 12 pass.
- `test_compute_fov.py` also passes, and `pytest -k "affine or fov or space or reslice"` gives 362 passed, 11 skipped.

**Behaviour changes, including the Python API**
- `-p N mm` now means millimetres; before, it meant voxels. The same applies to library callers of `compute_fov`/`fov_max`/`mean_space` with `pad_unit='mm'`, for example `tools.registration.objects.MeanSpace` and autoreg.
- `-l` and `--gpu` now take effect.
- `-o no` without `-r` writes nothing.

**New issues noticed, not fixed** (added to #171):
- The generic exception handler in `cli()` is commented out.
- `fileparts` values are reassigned inside the reslice loop. That's harmless today, but fragile.
- `setup_device` now exists in three places (register, uniseg, meanspace) and could be shared.
