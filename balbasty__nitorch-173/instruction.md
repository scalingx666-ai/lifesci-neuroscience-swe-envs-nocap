# Issue

**Title:** FIX(reslice): default output template raised KeyError 'sep'

## Description

Part of balbasty/nitorch#171.

## Summary
`nitorch reslice IMG -t REF`, run without `-o`, crashed with `KeyError: 'sep'`. The volume branch of `write_volumes` formatted the output template without the `sep` placeholder, while the default template is `{dir}{sep}{base}.resliced{ext}`. The streamline branch already passed `sep`.

## Changes
- Pass `sep=os.path.sep` when formatting volume output names.
- Add `nitorch/tests/test_cli_reslice.py`, which reslices a small volume onto itself without `-o` and checks the default output name and its content. The test fails before this fix.

## Test plan
