# Issue

**Title:** FIX(register): fixed-side affine Jacobian uses the forward pass's bound/extrapolate

## Description

## Summary

Part of #114 ().

In `do_affine`, the forward pass samples the displacement at the right grid with `smart_pull_grid(phi00, right, bound='zero')`, which has `extrapolate=True`. The fixed-side Jacobian of that displacement was sampled with `grid_jacobian`'s defaults instead: `bound='dft'`, and `extrapolate=False` passed explicitly. When a right affine is set, `grid_jacobian` already samples the gradient of the linear interpolant (`grid_grad`), so the only difference was these settings. They matter when the displacement is non-zero near the field's border.

- `pairwise_impl.py`: `grid_jacobian(phi00, right, type='disp', bound='zero', extrapolate=True)`.
- `test_register_affine_grad.py`:
  - New `test_affine_grad_deformed_border[s|f × fwd|sym]`: coarse field, displacement **not** windowed to zero at the border, full affine, gradient vs central FD.
    - Before this PR: relative error 0.54–1.6%.
    - With it: below 1e-4.
  - `make_svf`/`setup` take `border=True` (the default keeps the zero band, so the other tests are unchanged).
  - Corrected the `test_affine_grad` docstring: it described the fixed-side Jacobian as a finite-difference Jacobian.

**Not changed:** the ~1e-5 fixed-side residual on the coarse field in the existing tests. Those fields are zero near the border, so this change leaves them bitwise unchanged (1.38e-5 / 1.53e-5 before and after). That residual has another, unidentified cause and is kept as is, per the maintainer.
