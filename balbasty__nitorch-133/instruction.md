# Issue

**Title:** Fix backtracking on affine params, lr applied twice in StepSizeLineSearch, forced TkAgg backend

## Description

Part of #114. , which was merged before these changes were added. It fixes the three items #131 listed as found but not fixed.

## Summary
- **`@@optim gn -s N` crashed for affine registration.** Two bugs:
  - `AffineModel.Parameters` (`objects.py`) had no `clone()`/`copy_()`. It now has both:
    - `clone()` returns a `Parameters` with its own storage, so `add_` keeps switching from the optimised basis to the full basis.
    - `copy_()` accepts a `Parameters` or a full-basis tensor.
  - `BacktrackingLineSearch` called `optim.update(param0.clone(), delta)`, but the signature is `update(step, param)`. The arguments are now in the right order.
  - Powell, OGM and LBFGS do not use these paths. Their tests pass, including with `--runslow`.
- **lr was applied twice by `StepSizeLineSearch`.** Every search direction already includes `lr`:
  - GD, Momentum, Nesterov and OGM via `grad.mul(-lr)`;
  - LBFGS via `delta.mul_(lr)`;
  - the GN variants via `step.mul_(-lr)`.

  The search then multiplied by `lr` again, so the effective step was lr². It now searches over a backtracking factor that starts at 1. With `store_value`, it stores `lr × factor × store_value` on the optimiser, which matches `BacktrackingLineSearch`. GN uses `BacktrackingLineSearch`, which re-calls `search_direction` with the trial `lr`, so it was not affected.
- **`-v ≥ 2` forced `matplotlib.use('TkAgg')`**, which crashes when tkinter or a display is missing.
  - The call is removed (`register/cli.py`). matplotlib's default backend selection already honours `MPLBACKEND`/matplotlibrc and falls back to Agg when headless.
  - Plotting only happens at `-v ≥ 3`. Figure creation in `pairwise_run.py`/`pairwise_impl.py` now goes through `_new_figure()`. If matplotlib is not installed, or a figure cannot be created, it returns None (with a warning when a figure fails), and live plotting is skipped. The CLI also warns at `-v ≥ 3` when matplotlib is missing.
  - The same hard-coded `TkAgg` call exists in `cli/segmentation/uniseg/cli.py`. It is outside the registration CLI and is left as is.

## Tests
New tests in `nitorch/tests/test_line_search.py`:

- `register @affine rigid @@optim gn -s 3` and `-s wolfe` on a Gaussian blob shifted by 1 voxel recover the shift at the blob centre (±0.1). The `-s 3` case crashed before.
- `register -v 2` and `-v 3` run in a subprocess without `MPLBACKEND`, `DISPLAY` or `WAYLAND_DISPLAY` (no tkinter here) and exit with status 0. Both crashed before. The test is skipped if matplotlib is missing.
