- **topup**: the `-w` default is now `8 4 1` (coarse-to-fine voxel sizes in mm), as in the code.
- **inpaint**: the docstring's default suffix is now `.inpaint`. Removed text pasted from other commands.
- **vopt**:
  - The help defaults now match the code: `-m`/`-b`/`-l` 1e-4, and output `{dir}/{label}_optimal.lta`.
  - `-i` is described as an SVF.
  - The `-w` arguments are listed.
  - Removed the docs caveat that said the help disagreed with the code.
