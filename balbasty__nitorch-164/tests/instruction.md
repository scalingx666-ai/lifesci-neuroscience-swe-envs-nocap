# Issue

**Title:** EMMI: automatic per-level number of fixed bins (-d auto)

## Description

## Summary

Adds an opt-in automatic number of fixed-image bins for `@loss emmi` (`@@fix -d auto` or `-d auto:MX`; Python: `make_image(..., discretize=('auto', max_bins, nclasses))`, rule in `pairwise_preproc.auto_bins`).

**Rule.** At each pyramid level, with N valid voxels and K moving classes:

    J = clip(floor(N / (5 K)), 2, MX)      (MX = 256 by default)

This keeps the expected count per cell of the J×K joint histogram at 5 or more (the usual chi-square/multinomial rule of thumb). The plug-in MI bias grows like (J-1)(K-1)/2N. With 256×16 cells and 512 or 64 voxels, that bias is larger than the signal. Each pyramid level already gets its own discretised fixed image (`make_image` discretises after building the levels), so J is chosen per level. With emmi, K comes from the moving `-d` (default 16).

**Default unchanged.** `-d` still means 256 bins. Auto gives 256 at full resolution only when N ≥ 20480 voxels, so making it the default would change results on small images. It is opt-in for that reason.

**Cache.** `EMMI` now drops a cached H whose (J, K) shape does not match the inputs. This happens when J changes between levels. Previously a 256-row H would have been reused with a 51-bin image. The "drift" from the cache is documented: a warm start changes the value only through the EM stopping rule (`tolerance`, `max_iter`). A test checks that warm and cold starts agree within 1e-4 at tol 1e-8.

### Before/after: value -L/N at moving shifts 0/2/4/8 voxels (32³ noisy blobs, K=16)

| level (N) | bins | J | shift 0 | 2 | 4 | 8 |
|---|---|---|---|---|---|---|
| 0 (32768) | 256 / auto | 256 | -0.153 | -0.127 | -0.095 | -0.050 |
| 1 (4096) | 256 | 256 | -0.283 | -0.245 | -0.201 | -0.128 |
| 1 (4096) | auto | 51 | -0.268 | -0.208 | -0.156 | -0.080 |
| 2 (512) | 256 | 256 | -0.388 | -0.356 | -0.319 | -0.235 |
| 2 (512) | auto | 6 | -0.188 | -0.152 | -0.143 | -0.070 |
| 3 (64) | 256 | 256 | -0.527 | **-0.601** | **-0.614** | -0.412 |
| 3 (64) | auto | 2 | -0.0805 | -0.0805 | -0.0805 | -0.0802 |

With 256 bins the coarsest level has its minimum at a wrong shift. With auto it is almost flat (2 bins) and has no spurious minimum. At level 2, auto has a smaller overfit bias and a sharper relative contrast.

End-to-end (`register @loss emmi`, translation, GN 50, `--levels 0:3`, 24³ pair, true shift [3, -2, 1.5]): max error is 0.05 mm with `-d auto`, 0.07 with `-d 256` and 0.15 with `-d 32`.
