# Issue

**Title:** Fix affine penalty with progressive affine (-g)

## Description

## Summary
- The affine L2 penalty (`AffineModel.penalty`, one value per **model-basis** parameter, off by default) was added directly to the affine gradient/Hessian in `do_affine` / `do_affine_only`. With `-g` those are in the optimised **sub-basis**, so it failed with a shape mismatch (`size of tensor a (6) must match ... b (12)`, e.g. `affine` model with `optim='rigid'`).
- New helper `PairwiseRegisterStep._affine_penalty` computes the penalty in the model basis and maps it with the Gram matrix `M` (the same one used by `_optim_grad` / `Parameters._switch`): grad += Mᵀ(P ⊙ q), Hess += Mᵀ diag(P) M (full Hessian, which matches the existing format). Without `-g`, gradient and Hessian are computed exactly as before.
- Value term: the penalty value was counted twice: `sumloss += lla` in the step functions, then again in `self.print`, which assembles the total objective (data + llv + lla) on every evaluation. The extra `sumloss += lla` is removed. `print` is unchanged apart from a comment saying it assembles the objective and must be called exactly once per evaluation. This changes the reported objective value when a penalty is set, with or without `-g`.

## Tests
New tests in `test_register_symmetric.py`:
- **Affine penalty with `-g`** (rigid or similitude inside an affine model, `do_affine_only` and `do_affine`):
  - gradient and Hessian have the sub-basis shapes;
  - the gradient matches finite differences along the optimised directions;
  - the penalty terms equal Mᵀ(P⊙q) and Mᵀdiag(P)M.
- **Without `-g`:** gradient and Hessian are bitwise identical to the previous formula.
- **Penalty value vs gradient** (affine-only, joint affine+nonlinear, nonlinear-only; with and without `-g`): the difference between the penalised and unpenalised objectives matches the difference between their gradients by central differences. This would catch a penalty counted twice or left out.
- **Verbose 0/1/3**, inside and outside a line search, give bitwise-equal objectives, gradients and Hessians.
