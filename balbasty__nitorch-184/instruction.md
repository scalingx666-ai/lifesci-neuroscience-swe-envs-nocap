**Title:** FIX(info, view): info -s yes/no, field-of-view centre, view debug prints

## Description

Part of #171.

**`info`**
- **`-s`/`--stat` with a value.** The parser accepted only values starting with `t` or `f` and passed everything else to `bool(int(val))`. So `-s no` and `-s yes` crashed with "invalid literal for int()". It now uses `cli.Conversions.bool`, which accepts true/false, yes/no and 1/0, and raises `ParseError` for any other value. The help now shows `-s [BOOL]`.
- **Centre.** The centre of the field of view was computed at voxel `shape/2`, which is half a voxel off. Voxel centres sit at integer indices, so the true centre is at `(shape-1)/2`. **This changes the value that `info` reports**, and the docs example is updated to match.
