# Issue

**Title:** register: print the size of each update (disp column) when used for early stopping

## Description

## Summary
This is a , and part of #266. When an optimiser stops on the size of its updates (`@@optim -d`, on by default with the conservative defaults), the iteration table gets a `disp (vox)` column.

**What it shows.** The RMS displacement of the update since the previous printed row of the same component (affine or nonlinear). It uses the same measure as the stopping criterion: each image's own voxels at the current level, with both images for symmetric losses.
- The first row of a component is blank, since it has no previous iterate.
- On the last row, the value is the update that the criterion measured (`optim.iter.last_step_size`).

**When it appears.** The column is only printed when the criterion is in use (`-d` > 0). Nothing is computed or copied at `-v 0`.

Example (small synthetic pair):

```
step     | it  |     fit      +    affine    =     obj      |     gain     |  disp (vox)
-----------------------------------------------------------------------------------------
(affine) | 000 |  0.000124354 +            0 =  0.000124354 |              |
(affine) | 001 |  0.000114856 +            0 =  0.000114856 |  9.49809e-06 |    0.0441275
(affine) | 002 |  0.000114241 +            0 =  0.000114241 |  6.15606e-07 |   0.00293109
(affine) | 003 |  0.000114181 +            0 =  0.000114181 |  6.02183e-08 |  0.000287208
(affine) | 004 |  0.000114181 +            0 =  0.000114181 |  8.95307e-12 |  4.27077e-08
```

The nonlinear table gets the same column after `gain`, and its separator line is 15 characters wider.

## Implementation
- `PairwiseRegister._set_step_sizes()` now returns the hooks it attaches. It is called before the header is printed (the column is added only when hooks exist), and the hooks are shared with the step through `step.disp_hooks`.
- `PairwiseRegisterStep.print(..., param=None)` computes the column for normal evaluations. It keeps a copy of the parameters at the last printed row of each component: one extra copy, and only when the column is shown.
- `do_vel`, `do_affine` and `do_affine_only` pass their parameters to `print`.

## Tests
- `nitorch/tests/test_register_disp_stopping.py`, 4 new tests:
  - for affine and nonlinear, the header has the column, and every row has the same number of cells as the header;
  - the first row is blank, and the last row's value equals the iterator's `last_step_size`;
  - with `-d 0`, there is no column.
- Full suite (TS backend, torch 2.15): 4430 passed, 114 skipped, 0 failed.
