## Description

Part of #171. I reproduced each bug before fixing it.

3. **`greeq -v`** defaulted to 0 in the parser, but the help says `[1]`, and both `GREEQOptions` and `estatics` default to 1. **It now defaults to 1**; `-v 0` silences it.
4. **`greeq --lam-X 0`** fell back to `--lam`, because the code tested the value for truthiness. It now falls back only when the value is `None`.
