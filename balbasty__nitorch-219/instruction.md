**Fixes**
- **`-a/--align`** used to have no effect. It now controls `do_affine`: `always` (the default; also a bare `-a` and `yes`), `once`, and `no`/`--no-align`. With `--no-align`, the `mni`/`wrp` outputs fall back to an identity affine, so they use the image's own orientation.
- **`--mrf no`/`false`** were accepted but did not switch the MRF off. They do now.
- **Invalid `-a`/`--mrf` values** now give a clear error that lists the allowed values.
- **Output flags:**
  - the `--prior-*`/`--nobias-*` file names are fixed;
  - `--all-mni` now writes the probabilities and labels;
  - the `wrp` outputs are fixed, including the inverse used for `prior_wrp`.
- **A second `del mu_mni`** crashed some output combinations. It is removed.
- **A bare `-m` (and `-p`)** with no file is now a parse error, instead of silently taking the next tag.
- **Multi-channel `--bias-SPACE`/`--nobias-SPACE`:** with several inputs, these flags now write one file per channel.
  - Each file is named after its input's `{base}`.
  - Templates may use `{c}`, the 1-based channel index.
  - If names still collide, `.{c}` is added before the extension.
  - The nobias loops now actually write the bias-corrected images.
