## Summary

When all penalty factors are zero, `nn.GridLoss.forward` tried to reduce the python integer `0`:

```
TypeError: mean(): argument 'input' (position 1) must be Tensor, not int
```

autoreg builds such a loss for every linear transform, so any registration with only `-tr`/`-rig`/`-sim`/`-aff` (no FFD/diffeo) crashed. `GridLoss` now returns a tensor of zeros in that case.

This touches the same function as the linear-elastic factor PR, but different lines, so the two merge independently.
