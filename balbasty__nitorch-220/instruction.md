## Description

Part of #171. This follows up on the earlier autoreg fixes. I reproduced each item before fixing it.

**Fixes**
- **Negative numbers** such as `-w -1` or a factor of `-0.5` were parsed as tags. A dash-prefixed argument is now a tag only if it is not a number. This is the same rule as #211, implemented locally in autoreg's parser so this PR does not depend on #211.
- **`nitorch autoreg` with no arguments** crashed. It now prints the help.
- **Error handling:** the generic `[ERROR]` handler is restored. Failures print one line to stderr and return exit status 1, following the convention from #213.
- **`-oth` summary** crashed. The summary now prints, and `NoLoss` is named `other`.
- **`-g`** had no effect. It now sets the FFD node grid, with a default of 10. `FFD.free()` keeps the node grid across pyramid levels, and the affine factor used by `write_transforms` is fixed.
- **`ReduceLROnPlateau`** is now given `float(loss)` instead of a tensor.

**⚠️ Behaviour change:** `-ffd` now really uses a 10-node grid, or the grid set by `-g`. Its outputs therefore have the node-grid shape, with their own orientation matrix, instead of a dense field on the image grid. The old behaviour ignored `-g`, so outputs from earlier runs will not match.

**Docs:** a writer subagent updated `docs/cli/reference/registration/autoreg.md`. It covers negative values, `-g`, the FFD grid across pyramid levels, the FFD output, `-init`, the `-oth` example, and the errors and exit status.

**Tests:** all 20 tests in `nitorch/tests/test_cli_autoreg.py` pass.
