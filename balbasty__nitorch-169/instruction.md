# Issue

**Title:** mi: differentiate the joint histogram with respect to the moving image only

## Description

## Summary
This is the NMI item of #158. `mi()` and `entropy()` computed the joint histogram's derivatives with respect to **both** images and kept `[..., 0]`, the moving image. On the Hessian, half of the cost was thrown away: it is a loop over spline nodes, once per component.

The call site stays general, as discussed in #154: an option says which components are needed.

Two commits:

1. **`JointHistCount`: derivatives along a subset of components.**
   - `backward(..., axes=(0, 1))` and `backward_hess(..., axes=(0, 1))` keep their current default, and return `(..., n, len(axes))`. The Hessian loop only runs over the requested axes. The gradient still uses `grid_grad`, which computes both components cheaply, and selects the requested ones.
   - New `backward_grad_hess(..., axes)` returns the gradient and Hessian together. With spline order ≥ 2, they share the spline weights and the gathers from the histogram gradient. Order 1 computes them separately, because its Hessian uses the order-2 spline.
   - The three methods share their preprocessing (`_prepare_backward`).
2. **`mi`/`entropy` request `axes=[0]`**, and use `backward_grad_hess` when both derivatives are needed.

## Effect
NMI (32 bins, cubic Parzen window), 192³ with a binary mask, 4-thread CPU, loss + grad + hess:

| backend | master | this PR |
|---|---|---|
| TS (default `pip install`) | 6.3 s | 2.6–3.1 s |
| C | 6.2 s | 4.3–4.7 s |

The C backend gains less because its histogram *forward* (`GridPush` into 1024 bins) is slower than the TS one: the loss alone takes 2.2 s on C vs 1.5 s on TS. Most of what remains is building the histogram, which is #156 (sampling).

Outputs (value, gradient, Hessian) are **bitwise identical** to master on the TS backend. The comparison covered:
- 2D and 3D, 1–2 channels;
- float32 and float64;
- spline orders 1–3, `fwhm` 0 and 2;
- all four normalisations, with and without a soft mask;
- loss+grad and loss+grad+hess.
